## Features

- **Keydoor Method**  
  Key duplication using Xbox controller emulation

- **Throwable Dupe**  
  Throwable item duplication with auto-loop

- **Triggernade Dupe**  
  Triggernade duplication with inventory drop

- **Duck Duplication**  
  Duck item duplication 

- **E-Spam Collection**  
  Rapid `E` key spam for fast item pickup

- **Manual Disconnect**  
  Toggle packet drop (inbound / outbound)

## Instructions

### Ammo Dupe

1. Only have **one gun equipped** (nothing in the second weapon slot).
2. Click **Record**.
3. Right-click the weapon in the top slot.
4. Select `Unload weapon`.
5. Drag it to the **last slot in your inventory**.

**Recommended Settings:**

- Increase **`after context click`** to `~80–120`
- For pistols, set **`loop delay`** to `~800–1200`
- Slightly increase **`after double click`** if needed

---

### Keydoor Method

1. Record the **position of the key in your inventory** using the Record button.
2. Test before walking up to the door — ensure the key drops from inventory.
3. **VigEmBus installation required** (see link above). No setting changes should be necessary.
4. Make sure the item in inventory is **not highlighted**.
5. Open inventory **before pressing the hotkey**.
6. If it doesn’t work:
   - Drop the key manually
   - Pick it back up
   - Sometimes the controller bugs out and doesn’t show the drop option
